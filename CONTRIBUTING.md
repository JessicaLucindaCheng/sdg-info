# How to Contribute 
See the [Hack for LA Site Team's CONTRIBUTING.md](https://github.com/hackforla/website/blob/gh-pages/CONTRIBUTING.md) file for general instructions on how to fork, clone, and contribute to a repository (repo) and extrapolate for this repo.

Base your working/issue branch on the `main` branch.

When opening a pull request, set the following at the top:
 - **base repository:** `hackforla/sdg-info`
 - **base:** `main`
 - **head repository:** `{YOUR-GITHUB-HANDLE}/sdg-info`, where {YOUR-GITHUB-HANDLE} is your GitHub handle
 - **compare:** {YOUR-BRANCH}, where {YOUR-BRANCH} is your working/issue branch.
For more information, see GitHub's [Creating a Pull Request from a Fork](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork) guide.
